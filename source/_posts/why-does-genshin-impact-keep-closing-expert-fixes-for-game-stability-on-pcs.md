There are mainly two ways you can update the graphics driver:

**Option 1 – Manually** – GPU manufacturers will regularly optimize their graphics drivers for the latest titles. To get them, you need to go to the driver section of your GPU manufacturer:

* **[AMD](https://www.amd.com/en/support)**
* **[NVIDIA](https://www.nvidia.com/Download/index.aspx)**

 Find the correct driver that’s compatible with your system and download it manually. Upon completion, double-click the downloaded file and follow the on-screen instructions to install the driver.

### Fix 3 – Adjust the in-game settings

 According to Square Enix support, Outriders crashing occurs mostly on the -60 class GPUs, and tweaking the in-game graphics settings would make it run more smoothly. You can try this setup and see how things go.

1. Run your Outriders and go to the**Game Menu** .
2. Select**Options** .  
![](https://images.drivereasy.com/wp-content/uploads/2021/03/in-game-settings-1.jpg)
3. Under the**Display** tab, set the parameters as follows:  

**Windows Mode** :_Borderless_ or_Windowed_  
**VSync** :_Off_  
**Enable FPS Limit** :_On_  
**FPS Limit** : Set the value to_between 30 and 60_

 While doing this may decrease the visual performance, it’s an effective workaround for Outriders inventory/menu crashes before the full version launches.
